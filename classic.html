How it works

Four steps. No waiting, no downloading, no AI scan of a 12-hour VOD.

01

Record live

streamlink records the stream from the very first second. Nothing to download later.

02

Count chat

Every 10 seconds it counts chat messages — Twitch via anonymous IRC, YouTube via chat-downloader. No login, no API key.

03

Chat explodes → cut

A window is a spike when it beats the floor and 3× the recent baseline. FFmpeg cuts 30 seconds: 25s before, 5s after.

04

Post first

Whisper adds captions, optional 9:16 vertical export for Shorts and Reels. Your clip is ready before the stream ends.

Everything in the box

Twitch + YouTube Live

One command for both. Auto-detects the platform from a channel name, video URL, video ID, or @handle/live.

Vertical 9:16 export

--vertical turns every clip into a 1080×1920 Shorts / Reels / TikTok cut with a blurred-background fill.

Whisper captions

Captions are burned into each clip automatically when openai-whisper is installed.

Thumbnails

--thumbnails saves a still from the middle of every clip, ready to post with.

Wait for live

--wait-for-live sits patiently until the stream starts instead of exiting. Perfect for launch night.

Tuning log

Every 10-second window is logged to windows.csv with its count, baseline, and spike flag — tune your thresholds from real data.

Offline simulator

--simulate-chat replays a chat log and tells you which windows would have clipped, before you go live.

Install

Python 3, streamlink, ffmpeg. YouTube chat needs chat-downloader. Captions need Whisper (optional).

# recorder (Twitch + YouTube)
pip install streamlink

# YouTube live chat (only needed for YouTube)
pip install chat-downloader

# captions (optional)
pip install openai-whisper

# ffmpeg must be on PATH — most systems already have it

Use it

# Twitch
python3 liveclip.py shroud --out gta6-launch --min-spike 40

# YouTube Live — video URL, video ID, or @handle/live
python3 liveclip.py https://www.youtube.com/watch?v=VIDEO_ID --vertical
python3 liveclip.py dQw4w9WgXcQ --vertical --thumbnails
python3 liveclip.py @SkyNews/live --wait-for-live

# test your thresholds offline first
python3 liveclip.py --simulate-chat chat-sample.txt

Tuning

SituationWhat to change
Big launch night (GTA 6)Raise --min-spike (e.g. 100) so only real explosions clip
Small streamLower --min-spike (e.g. 10) or the floor never triggers
Too many clipsRaise --cooldown (e.g. 180)
Not sureCheck windows.csv after a run and adjust from real data

Honest limits

  • Run it on your own machine. The chat connections need direct network access.
  • A chat spike is a proxy for a good moment, not a guarantee — check clips before posting.
  • Stream-copy cuts start at the nearest keyframe, so a clip can start a second or two early.
  • It only works live. Once the stream ends, so does the advantage.
